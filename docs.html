Docs

Hone in the workshop, then wire the mill.

Create a simulation run. Ingest a production call. Fetch scores. SDKs ship for Node and Python. Base URL: https://api.stropel.xyz/v1.

Scenarios

A scenario is a scripted goal plus optional turn hints. Stropel fills speech from the persona. Freeze a suite with a suite_id so prompt diffs compare the same leather.

{
  "scenario_id": "scn_identity_then_refund",
  "goal": "Verify the caller, then quote a refund.",
  "channel": "voice",
  "success": ["identity_matched", "refund_quoted_after_verify"],
  "traps": ["refund_before_verify", "accept_third_party_dob"]
}

Personas

Personas stamp accent, noise, emotion, interrupt timing. Attach one or many to a run. The sample below is the kitchen-noise refund caller used on the product page.

{
  "persona_id": "prs_mumbai_kitchen_08",
  "locale": "en-IN",
  "accent": "Mumbai English",
  "noise_db": 58,
  "interrupt_s": 8,
  "emotion": "impatient"
}

CI

Edge and Mill. The job posts a run, waits, then fails if any required metric is below the floor.

# .github/workflows/stropel.yml
name: stropel-suite
on: [pull_request]
jobs:
  hone:
    runs-on: ubuntu-latest
    steps:
      - uses: stropel/gate-action@v1
        with:
          suite_id: suite_support_v3
          floors: '{"goal":80,"policy":90}'
          api_key: ${{ secrets.STROPEL_API_KEY }}

Scoring

Each row gets 0 to 100 on every metric in the rubric. Pass, warn, and fail bands are yours. Defaults: pass at 80, warn at 65, fail below 65. Policy fails closed: a policy fail holds the run even when goal is high.

Webhooks

POST JSON to your URL when a run finishes or a live call fails a floor. Signatures use HMAC-SHA256 in header X-Stropel-Signature.

{
  "event": "run.completed",
  "run_id": "stropel_run_7f3a",
  "overall": 68,
  "decision": "hold",
  "fails": ["goal", "policy"]
}

Privacy of recordings

Call recordings and scores are customer data. You set retention. Deletion on request, legal holds excepted. Stropel staff need an explicit ticket to open a recording. Mill can pin region: US-West or EU-Central.

API

Authenticate with Authorization: Bearer sk_live_.... Node package @stropel/sdk. Python package stropel.

Create a simulation run

curl -X POST https://api.stropel.xyz/v1/runs \
  -H "Authorization: Bearer $STROPEL_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "suite_id": "suite_support_v3",
    "agent": {
      "id": "support-v3.2.1",
      "endpoint": "wss://voice.northline-support.net/session"
    },
    "count": 40
  }'

Ingest a production call

curl -X POST https://api.stropel.xyz/v1/calls \
  -H "Authorization: Bearer $STROPEL_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "agent_id": "support-v3.2.1",
    "audio_url": "s3://northline-calls/call_4419.wav",
    "started_at": "2026-08-12T17:58:02Z"
  }'

Fetch scores

curl https://api.stropel.xyz/v1/runs/stropel_run_7f3a/scores \
  -H "Authorization: Bearer $STROPEL_KEY"
{
  "run_id": "stropel_run_7f3a",
  "overall": 68,
  "decision": "hold",
  "metrics": {
    "goal": 62,
    "policy": 41,
    "pronunciation": 94,
    "latency_p50_ms": 810,
    "tone": 88,
    "interrupt": 71
  }
}

Node

import { Stropel } from "@stropel/sdk";
const client = new Stropel({ apiKey: process.env.STROPEL_KEY });
const run = await client.runs.create({
  suiteId: "suite_support_v3",
  agentId: "support-v3.2.1",
});
const scores = await client.runs.scores(run.id);

Python

import os
from stropel import Client
client = Client(api_key=os.environ["STROPEL_KEY"])
run = client.runs.create(suite_id="suite_support_v3", agent_id="support-v3.2.1")
scores = client.runs.scores(run.id)
